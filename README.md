# Dart Method Generator

A Visual Studio Code extension that helps you quickly generate common methods for Dart classes.

## Features

- Generate constructor with parameters
- Generate copyWith method
- Generate JSON serialization (toJson/fromJson)
- Generate equality methods (== operator and hashCode)
- Generate all methods at once

## Usage

1. Open a Dart file in VS Code
2. Select a class definition or position your cursor inside a class
3. Right-click and select "Generate Dart Methods" from the context menu
4. Choose which methods to generate:
   - Generate All Methods (constructor, copyWith, serialization, equality)
   - Generate Constructor
   - Generate copyWith
   - Generate Serialization
   - Generate Equality
